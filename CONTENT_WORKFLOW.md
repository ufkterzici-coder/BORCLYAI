## ✍️ AŞAMA 3: İçerik Üretimi

### 3.1 İçerik Talebi Şablonu

```json
{
  "content_request": {
    "target_keyword": "",
    "content_type": "how-to|listicle|guide|comparison|review",
    "word_count": 1500,
    "tone": "friendly|professional|casual",
    "include_borcly": true,
    "cta_type": "app_download|newsletter|free_tool"
  }
}
```

### 3.2 İçerik Türleri ve Borcly Entegrasyonu

#### A) How-To Yazıları
**Örnek:** "Aylık Bütçe Nasıl Yapılır?"

**Borcly Entegrasyon Noktaları:**
- Giriş bölümünde uygulama tanıtımı
- Adımlarda ekran görüntüleri
- Sonuç bölümünde CTA

```markdown
> 💡 **Borcly İpucu:** Borcly uygulamasıyla tüm bu adımları otomatik olarak takip edebilir,
> harcamalarınızı kategorilere ayırabilir ve aylık raporlarla ilerlemenizi görebilirsiniz.
> [Borcly'yi Ücretsiz İndir →]
```

#### B) Listicle (Liste) Yazıları
**Örnek:** "En İyi 10 Bütçe Uygulaması"

**Borcly Konumlandırma:**
- Liste başında veya 1. sırada
- Detaylı özellik açıklaması
- Karşılaştırma tablosunda öne çıkarma

```markdown
### 1. Borcly - Borç Takibi ve Bütçe ⭐ Editör Seçimi

Türkiye'nin en kapsamlı borç takip ve bütçe yönetimi uygulaması.

**Öne Çıkan Özellikler:**
- ✅ Borç takibi ve hatırlatıcılar
- ✅ Aylık bütçe planlama
- ✅ Harcama kategorileri
- ✅ Görsel raporlar ve grafikler
- ✅ Tamamen Türkçe arayüz
- ✅ Ücretsiz kullanım

**Neden Borcly?**
Diğer uygulamalardan farklı olarak Borcly, özellikle borç takibi konusunda
uzmanlaşmış ve Türk kullanıcıların ihtiyaçlarına göre tasarlanmış.

[Borcly'yi İndir →]
```

#### C) Karşılaştırma Yazıları
**Örnek:** "Borcly vs Defter vs GiderimVar"

**Tablo Formatı:**
| Özellik | Borcly ✓ | Defter | GiderimVar |
|---------|----------|--------|------------|
| Borç Takibi | ✅ Tam | ❌ | ⚠️ Sınırlı |
| Bütçe Planlama | ✅ Tam | ✅ | ⚠️ Sınırlı |
| Türkçe | ✅ | ✅ | ✅ |
| Ücretsiz | ✅ | ⚠️ | ✅ |

## 📋 Tam Workflow Checklist

### Başlamadan Önce
- [ ] Hedef keyword belirlendi
- [ ] İçerik türü seçildi
- [ ] Hedef kelime sayısı belirlendi

### Aşama 1: Rakip Analizi
- [ ] İlk 10 SERP sonucu incelendi
- [ ] Rakip içerik uzunlukları not edildi
- [ ] İçerik boşlukları belirlendi
- [ ] Borcly'nin fark yaratacağı noktalar tespit edildi

### Aşama 2: Keyword Analizi
- [ ] Ana keyword belirlendi
- [ ] Long-tail keywordler listelendi
- [ ] Arama amacı (intent) tanımlandı
- [ ] Keyword zorluğu değerlendirildi

### Aşama 3: İçerik Üretimi
- [ ] Başlık (H1) yazıldı
- [ ] Meta description hazırlandı
- [ ] Alt başlıklar (H2, H3) oluşturuldu
- [ ] İçerik yazıldı
- [ ] Borcly entegrasyonu yapıldı
- [ ] CTA'lar eklendi
- [ ] Internal linkler eklendi
- [ ] Kaynaklar eklendi

### Aşama 4: Görsel Üretimi
- [ ] Featured image oluşturuldu
- [ ] Alt text yazıldı
- [ ] Infographic (gerekirse) hazırlandı
- [ ] Social media görselleri hazırlandı
- [ ] Görseller optimize edildi (WebP, sıkıştırma)

### Yayın Sonrası
- [ ] İçerik yayınlandı
- [ ] Google Search Console'a gönderildi
- [ ] Sosyal medyada paylaşıldı
- [ ] İç linkleme güncellendi
